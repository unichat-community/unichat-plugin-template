# UniChat Plugin Template

This is a template for creating plugins for UniChat. It provides a basic structure and example code to help you get started with developing your own plugin.

Read the docs under [UniChat Plugin Development](https://unichat.voguh.me/docs/1.4.x/plugins/getting_started.html) for more detailed information on how to create and manage your plugins.
